## Ассеты
- [ ] Логотип и иконки таб-бара в SVG.
- [ ] Название шрифта заголовков.
- [ ] **Баг API: эффективность стилей.** В `/api/ArmWrestler/{id}/stats` → `styleEffectiveness` «общие» поля (`powerDominance`, `tacticalEfficiency`, …) равны значению левой руки (у Лалетина 140.79 = `powerDominanceLeft`), а не общей оценке. Страница боя на сайте показывает именно их (141%, 102%). Приложение берёт значения руки боя. Также шкала не ограничена 100 — уточнить, что означают значения.
- [ ] **Сессия Keycloak — 1 час без активности.** Refresh-токен (JWT) живёт 60 минут, хотя кука `refresh_token` ставится на 7 дней; после часа простоя `/auth/refresh` → 401 (на сайте так же). Починка: Keycloak → realm `blackarm` → Realm settings → Sessions → SSO Session Idle ≈ 30 дней, SSO Session Max ≈ 90 дней; проверить, что у клиента API в Advanced → Client Session Idle/Max не задано меньшее. В приложении уже есть страховка: тихий повторный вход по почте и паролю из защищённого хранилища.
- [ ] **Вопрос к API: слои прогноза M.I.R.A.** Слой ML считается как `delta + 50` из `layerContributions` (так же на сайте) и может давать 100%, когда итоговый прогноз — 61/39 (бой Larratt — Kurdecha). Похоже, `delta` слоя ML не в той шкале или не ограничен; на сайте то же самое. Уточнить на бэкенде, как правильно переводить вклад слоя в проценты.
- [x] Уведомления: колокольчик с бейджем, экран уведомлений (те же шаблоны текстов, что на сайте), живые события через SignalR-хаб `/hubs/notifications` (JoinUserGroup по Keycloak sub), баннер внутри приложения, переход по ссылке уведомления в экран приложения.
- [ ] **Push-уведомления, когда приложение закрыто.** Хаб работает, только пока приложение открыто. Для системных push нужен FCM (Android) / APNs (iOS): сервер должен хранить токены устройств и слать push при тех же событиях. Требует доработки API + development build (в Expo Go push от своего сервера ограничены).
- [x] Общий поиск (лупа в шапке): атлеты, турниры, пользователи через /api/search; публичный профиль пользователя /user/{id} (скрытые разделы — заглушкой); ники в комментариях ведут на профиль автора.
- [ ] **Русские имена бойцов.** На бэкенде готово: API отдаёт имена кириллицей при заголовке `X-Lang: ru`, без заголовка — латиницей, как сейчас. В `rawFetch` (`src/api/http.ts`) добавить `headers.set('X-Lang', 'ru')`: подмена идёт на сервере, поэтому экраны менять не нужно, поиск по кириллице уже работает. Проверить: победитель и подсветка боя (`f.winner === f.wrestler1Name` — обе стороны приходят переведёнными, должно совпасть), длинные имена в карточках и шапках (самые длинные: «Маатеиваранги Хета-Моррис», «Ребека Мартинковичова»), шрифт заголовков на кириллице. Свободный текст M.I.R.A., новости и уведомления остаются с латинскими именами, названия турниров не переводятся. Подробности на бэкенде: `BlackArm.API/Localization/FighterNamesResultFilter.cs`.
